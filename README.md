# enredARTE web - prototipo 01

Primer prototipo estático de la web de enredARTE.

## Cómo verlo

Abrí `index.html` en el navegador.

## Archivos

- `index.html`: estructura de la home.
- `styles.css`: identidad visual y responsive.
- `app.js`: oportunidades mockeadas + filtro simple.
- `assets/hero-eyes.png`: imagen de hero tomada del material de referencia.

## Próximo paso recomendado

Convertir esta home estática en una estructura por páginas:

- Home
- Oportunidades
- Detalle de oportunidad
- Registro para artistas
- Registro para espacios
- Sobre enredARTE
